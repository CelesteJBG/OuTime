# OuTime

Aplicación móvil Android para la gestión y reserva de citas en pequeños negocios.

## Descripción

OuTime permite a clientes consultar negocios y servicios disponibles,
seleccionar horarios y gestionar sus citas. Los negocios pueden administrar
sus servicios, horarios, disponibilidad y reservas.

## Tecnologías principales

- Kotlin
- Jetpack Compose
- MVVM
- Firebase Authentication
- Firebase Firestore
- Kotlin Coroutines / Flow
- Navigation Compose
- JUnit

## Arquitectura

El proyecto sigue una arquitectura basada en la separación entre las capas
de presentación, dominio y datos.
